What is a Runtime Engine?
A Runtime Engine is the software that executes and manages your application's schemas, metadata, and generated components while the application is running.
Simple definition:
The Runtime Engine is the "brain" that reads schemas and decides what should happen when users interact with the system.
Simple Analogy
Think of a recipe.
Recipe (YAML/Schema) → Instructions
Chef (Runtime Engine) → Executes the instructions
Food (UI/Application) → Final result
Without the chef, the recipe cannot become food.
Without the Runtime Engine, schemas cannot become a working application.

What Does the Runtime Engine Do?
The Runtime Engine:
✅ Reads schemas
✅ Loads components
✅ Handles user interactions
✅ Executes validations
✅ Calls APIs
✅ Applies permissions
✅ Manages workflows
✅ Updates the UI dynamically
